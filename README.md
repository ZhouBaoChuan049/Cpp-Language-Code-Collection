##  模块划分与核心主题

###  第一部分：C++ 初阶与进阶/核心语法实践
本模块作为技术博客的早期连载源码，系统化地梳理了 C++ 面向对象的核心基础。

###  第二部分：STL 核心容器底层模拟实现 (主打硬核模块)
本模块对标准模板库（STL）中难度最高、应用最广的底层数据结构进行了高仿真的“从零手写实现”，旨在深度攻克 C++ 内存指针控制与复杂算法逻辑：

| 模块名称 | 核心技术点 / 底层数据结构 | 实践价值 |
| :--- | :--- | :--- |
| **模拟实现搜索二叉树** | 二叉搜索树（BST）的增删查改 | 理解二叉树动态指针操作的基础 |
| **模拟实现list / string / vector** | 迭代器（Iterator）封装、空间配置器、写时拷贝 | 掌握 STL 三大核心组件的内部拓扑与动态内存扩容 |
| **模拟实现红黑树 / AVL树** | 平衡二叉树、三叉链结构、左旋/右旋、颜色红黑平衡调节 | 彻底攻克数据结构中的“大Boss”，掌握极端情况下的复杂平衡算法 |
| **模拟实现哈希（开放定址法/链地址法）** | 哈希函数、线性探测、哈希桶（开链法） | 深入理解哈希冲突的工业级解决方案 |
| **封装红黑树实现 map 与 set** | 泛型复用、红黑树迭代器的源码级封装 | 还原 STL 源码艺术，用**单张红黑树**完美复用并封装出 `map` 和 `set` |
| **封装哈希表实现 unordered_map/set** | 哈希桶的复用、K/V 类型的泛型泛化 | 深入探究 C++11 新标准容器的底层实现逻辑 |
